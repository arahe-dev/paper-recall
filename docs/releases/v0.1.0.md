Use the normal setup exe for the safest desktop test path. Use the frameless setup exe to test the custom traffic-light window controls.

## Highlights

- Native Windows desktop package through Tauri.
- Browser development mode remains available.
- Editable Excalidraw board.
- Local save, open, recent board, duplicate, rename, and delete flows.
- Template gallery.
- Recall Graph IR import.
- AI context and text graph exports.
- Transcript parser.
- Separate frameless custom-chrome build for testing.

## Security Notes

- The Windows installer is unsigned and may trigger SmartScreen.
- JavaScript audit still reports transitive advisories through Excalidraw's Mermaid parser dependency chain.
- Rust audit reports transitive Tauri/Linux GTK stack warnings; the current release target is Windows x64.
- No common committed secret patterns were found in the tracked-file scan.

See `docs/security-scan.md` for the scan details.
