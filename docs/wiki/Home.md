## Core Idea

Recall Board keeps the visual board editable for humans while exporting enough structured data for an AI to understand the board without a screenshot.

The app is built around three paths:

- Human board editing with Excalidraw.
- Structured board export for AI parse-back.
- Native desktop packaging through Tauri.

## Current Status

Version `0.1.0` is an early Windows test build. It is usable for board creation, local persistence, import/export, templates, transcript parsing, and AI context experiments.

The installer is not code signed yet. Treat it as a test build.
