### Highlights

- Tauri desktop app shell.
- Browser development mode.
- Local board save/open/recent-board flows.
- Excalidraw editor integration.
- Template gallery.
- Recall Graph IR import.
- AI context and text graph exports.
- Transcript parser.
- Optional frameless custom-chrome test shell.

### Limitations

- Unsigned Windows installer.
- Custom chrome remains a test path.
- Known transitive dependency advisories remain documented.
