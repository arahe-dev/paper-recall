# User Guide

## Home Screen

The home screen gives access to a new board, recent boards, and reusable templates.

## Boards

A board is an editable Excalidraw scene with Recall-specific save, import, export, and parse-back tools around it.

Use the toolbar to:

- Create a new board.
- Open an existing board.
- Save the current board.
- Save under a new name.
- Rename or duplicate a board.
- Delete a board entry.
- Open recent boards.

## Drawing

Use Excalidraw's normal tools for shapes, arrows, text, and freehand sketches.

Recall Board adds structure around the drawing so the board can later be exported as a compact graph or AI context file.

## Templates

Templates provide starting structures for common boards. After inserting a template, every object remains editable.

## Recent Boards

Saved and opened boards appear in the recent boards list. This is intended for fast local work rather than cloud sync.

## Transcript Parser

The transcript parser accepts terminal output, build logs, or agent session logs and extracts structured sections such as commands, errors, file changes, verification checks, commits, and next steps.

## Import and Export

Recall Board can import Recall Graph IR JSON and export board state in several forms. Use the export format that matches your next task:

- Excalidraw scene JSON for visual fidelity.
- AI context JSON for structured model input.
- Text graph JSON for compact graph parse-back.
- Prompt text for asking an AI to explain a board.
